# 术语、公式、接口与检查表

## 一、核心术语

| 缩写/术语          | 中文含义                   | 工程说明                               |
| :----------------- | :------------------------- | :------------------------------------- |
| UAV/UAS            | 无人驾驶航空器/系统        | UAS 还包含地面站、链路、人员和运行体系 |
| FC/Autopilot       | 飞控/自动驾驶仪            | 实时估计、控制、模式与安全核心         |
| GCS                | 地面控制站                 | 配置、任务、遥测、日志和载荷控制       |
| IMU                | 惯性测量单元               | 通常为三轴陀螺 + 三轴加速度计          |
| INS                | 惯性导航系统               | 对惯性数据积分得到姿态/速度/位置       |
| GNSS               | 全球卫星导航系统           | GPS、北斗、Galileo、GLONASS 等统称     |
| RTK                | 实时动态差分               | 载波相位差分高精定位，需关注解状态     |
| EKF/UKF            | 扩展/无迹 Kalman 滤波      | 非线性状态估计方法                     |
| VIO                | 视觉惯性里程计             | 相机 + IMU 的局部运动估计              |
| SLAM               | 同时定位与建图             | 估计轨迹并构建/优化地图                |
| ESC                | 电子调速器                 | 驱动无刷电机，可能带遥测               |
| BMS                | 电池管理系统               | 电芯采样、保护、均衡、状态估计         |
| PDB                | 配电板                     | 将电池主功率分配给 ESC/负载            |
| SoC                | 片上系统                   | 集成 CPU、GPU/NPU、ISP、接口等         |
| NPU/DSP/ISP        | 神经网络/信号/图像处理单元 | 各自针对特定计算模式                   |
| SITL/HIL           | 软件在环/硬件在环          | 不同层次仿真验证                       |
| Failsafe           | 失效保护                   | 检测异常后进入预定安全行为             |
| Geofence           | 地理围栏                   | 空间/高度约束，不等于完整空域许可      |
| Remote ID/运行识别 | 运行身份与状态发送         | 具体要求随国家/标准变化                |
| MAVLink            | 无人机轻量消息协议         | 消息/微服务，不是无线物理层            |
| uORB               | PX4 发布订阅中间件         | 机内模块数据交换                       |
| DShot              | 数字 ESC 命令协议          | 可配合双向遥测，配置须核对固件         |
| Cyphal             | 实时机载分布式通信协议     | 常运行于 CAN/CAN FD/UDP 等             |
| FOC                | 磁场定向控制               | 电机 dq 轴电流控制方法                 |
| TF                 | 坐标变换树                 | ROS 中管理随时间变化的坐标关系         |
| QoS                | 服务质量                   | 可靠性、历史、深度、截止期等策略       |
| SBOM               | 软件物料清单               | 记录依赖、版本和许可证/漏洞            |

## 二、单位和坐标速查

### 2.1 推荐 SI 单位

| 量               | 单位    | 常见错误               |
| :--------------- | :------ | :--------------------- |
| 角度（算法内部） | rad     | 与 degree 混用         |
| 角速度           | rad/s   | 数据手册为 °/s 未换算  |
| 加速度           | m/s²    | g 与 m/s² 混用         |
| 力/推力          | N       | kgf 与 kg 误作力       |
| 力矩             | N·m     | N·cm 未换算            |
| 压力             | Pa      | Pa/hPa 混用            |
| 电量             | C 或 Ah | Ah 与 Wh 混用          |
| 能量             | J 或 Wh | 忽略电压和效率         |
| 功率             | W       | 峰值与平均不分         |
| 频率             | Hz      | 采样率与带宽等同       |
| 时间             | s/µs/ns | 系统时间与单调时间混用 |

### 2.2 常用换算

$$
1\ \mathrm{kgf}=9.80665\ \mathrm{N}
$$

$$
1\ \mathrm{Wh}=3600\ \mathrm{J}
$$

$$
\mathrm{rad}=\mathrm{degree}\times\frac{\pi}{180}
$$

## 三、常用公式

### 3.1 运动与力

$$
\mathbf{F}=m\mathbf{a},\qquad \boldsymbol{\tau}=\mathbf{r}\times\mathbf{F}
$$

$$
E_k=\frac{1}{2}mv^2,\qquad E_p=mgh
$$

动能随速度平方增长，是高速飞行风险迅速增加的原因之一。

### 3.2 多旋翼

$$
T_i\approx k_T\omega_i^2,\qquad Q_i\approx k_Q\omega_i^2
$$

$$
P_{ideal}\approx\frac{T^{3/2}}{\sqrt{2\rho A}}
$$

### 3.3 固定翼

$$
L=\frac{1}{2}\rho V^2SC_L,\qquad D=\frac{1}{2}\rho V^2SC_D
$$

### 3.4 电源

$$
P=VI,\qquad E\approx V_{nom}C_{Ah},\qquad P_{copper}=I^2R
$$

$$
V_{load}\approx V_{oc}-IR_{internal}
$$

### 3.5 通信

$$
P_r=P_t+G_t+G_r-\sum L
$$

各量以 dB/dBm 一致表达。预算还需衰落裕量和法规限制。

### 3.6 控制和估计

$$
u=K_Pe+K_I\int e\,dt+K_D\dot e+u_{ff}
$$

$$
\mathbf{x}_{k+1}=f(\mathbf{x}_k,\mathbf{u}_k)+\mathbf{w}_k
$$

$$
\mathbf{z}_k=h(\mathbf{x}_k)+\mathbf{v}_k
$$

公式用于建立直觉，实际实现还需离散化、限幅、时延、坐标和数值稳定处理。

## 四、接口契约模板

每个跨模块接口至少填写：

| 字段           | 示例/问题                              |
| :------------- | :------------------------------------- |
| 名称和版本     | `vehicle_odometry v3`                  |
| 生产者/消费者  | VIO→飞控估计器                         |
| 传输           | UART/CAN/uORB/ROS 2/MAVLink            |
| 更新率与截止期 | 30 Hz；最大年龄 100 ms                 |
| 坐标系         | ENU/FLU 或 NED/FRD；原点定义           |
| 单位           | m、m/s、rad；禁止隐式缩放              |
| 时间戳         | 曝光中点；单调时钟；同步方式           |
| 不确定度       | 协方差定义和排列                       |
| 有效性         | tracking state、reset counter、quality |
| 失效行为       | 超时拒绝、保持多久、降级模式           |
| 安全           | 鉴权、权限、重放和范围                 |
| 测试           | 正常、乱序、NaN、跳变、超时、重启      |

## 五、飞控板选型检查表

- [ ] 目标机型、控制/估计频率和最坏延迟已定义。
- [ ] MCU Flash/RAM 有编译实测和增长裕量。
- [ ] IMU 数量、型号、总线、方向、振动和温度已评估。
- [ ] 气压计、磁力、GNSS、空速/测距接口满足任务。
- [ ] UART/SPI/I²C/CAN/定时器没有资源冲突。
- [ ] 主/备电源、输入范围、浪涌、监测和 brownout 已验证。
- [ ] SD/Flash 日志吞吐和掉电损坏策略已验证。
- [ ] SWD、Bootloader、恢复和量产测试点可用。
- [ ] 固件生态支持该板型和目标版本，不只是“相同 MCU”。
- [ ] 原理图、PCB、BOM、许可证和生命周期可获得。

- [ ] 适用法规、登记、空域、运行识别、人员和保险已核验。

## 十一、能力自测题

### 11.1 入门

1. NED 与 ENU 如何转换，为什么只交换 X/Y 不够？
2. IMU ODR、控制频率和滤波截止频率有什么区别？
3. KV 值为何不能直接代表电机最大推力？
4. GNSS 卫星很多为何仍可能位置错误？
5. 为什么拆桨调试是必要条件而不是建议？

### 11.2 中级

1. 如何测量 IMU 数据就绪到 DShot 更新的 P99 延迟？
2. 电机饱和时积分器和控制分配应如何处理？
3. VIO 回环导致位置跳变时如何保护位置环？
4. 视频与控制共链路时如何设计 QoS 和保底？
5. 双 IMU 在什么情况下不是有效冗余？

### 11.3 研发级

1. 为强磁环境任务设计航向可观性和降级策略。
2. 为 VTOL 转换建立控制分配、终止条件和测试矩阵。
3. 证明一个 AI 避障系统在 P99 延迟下仍满足制动距离。
4. 将运行识别、安全启动、OTA 和生产身份统一进信任链。
5. 从一次偶发重启建立可证伪假设并设计复现实验。

## 十二、建议的最小工具箱

### 软件

Git、VS Code、GCC/Clang、CMake、Python/Jupyter、NumPy/SciPy/Matplotlib、PX4 或 ArduPilot SITL、Gazebo、QGroundControl/Mission Planner、MAVSDK、日志分析工具、Wireshark、ROS 2（自主方向）。

### 硬件实验

万用表、限流电源、示波器、逻辑分析仪、温度测量、可靠焊接与 ESD 工具；动力实验另需专业推力台、防护罩和急停。工具能力不足时不要用真机冒险代替测量。

## 十三、最终学习完成标准

- 能从任务推导系统架构和预算，而非从芯片倒推需求。
- 能解释一条传感器到执行器的时间、坐标、单位和错误传播链。
- 能在 SITL/HIL 中复现正常与故障场景，并自动判定。
- 能用日志区分结构、传感器、估计、控制、电源和通信问题。
- 能在法规、安全、许可证和隐私边界内组织研发与试飞。
- 有至少一个完整作品，包含失败案例、回归证据和可复现版本。
