# 动力、电源、电子硬件、芯片与传感器

## 一、整机能量与航电架构

```text
电池包
  ├─ 主功率母线 ──> ESC ──> 电机 ──> 螺旋桨/旋翼
  ├─ 电源模块 ────> 飞控主电源/电压电流测量
  ├─ DC/DC ───────> 伴随计算、相机、图传、载荷
  └─ 备份/隔离电源 ─> 安全 MCU、定位或关键遥测（按需求）

飞控 MCU <──SPI/I²C/UART/CAN──> IMU、气压、磁力、GNSS、ESC、RC
    │
    └──UART/CAN/Ethernet──> Linux 伴随计算机 <──MIPI/USB──> 相机/深度/LiDAR
```

设计时必须同时画电源树、数据树、时钟/时间同步树和故障传播树。

## 二、电机、电调和执行器

### 2.1 BLDC/PMSM 关键概念

- KV 通常表示空载条件下每伏对应的转速常数数量级，不等于扭矩或效率。
- 扭矩与产生扭矩的电流分量相关；铜耗约为 $I^2R$。
- 反电动势随转速增加，电源电压、绕组和控制方式共同限制最高转速。
- 实际效率由电机铜损/铁损、电调损耗、机械损耗和桨气动效率共同决定。

### 2.2 电调

电调包含功率 MOSFET、栅极驱动、采样、控制 MCU 和固件。六步换相常见且成本低；FOC 可改善噪声、低速和平顺性，但算法、参数辨识和电流采样复杂。飞控关注的不只是协议能否通信，还包括：

- 命令到推力的时延和更新率。
- 最小可控转速、启动可靠性和堵转保护。
- 主动制动、再生能量和母线过压风险。
- 电流、温度、转速和错误遥测。
- 单个 ESC 故障是否拖垮电源或总线。

### 2.3 DShot、PWM 与 CAN 执行器

PWM 简单通用，但脉宽测量和校准会带来边界；DShot 使用数字编码并可支持遥测；CAN/Cyphal 执行器可提供寻址、状态和更丰富诊断，但总线、节点身份、带宽和故障隔离更复杂。

## 三、电池、BMS 和电源

### 3.1 电芯参数

| 参数     | 工程意义             | 常见误区                      |
| :------- | :------------------- | :---------------------------- |
| 标称电压 | 化学体系的名义平台   | 当作全程固定电压              |
| 容量 Ah  | 一定条件下可释放电量 | 与 Wh 混用                    |
| 能量 Wh  | 电压与容量的综合     | 忽略可用窗口和转换效率        |
| 内阻     | 决定电压下陷和发热   | 只看新品室温数据              |
| C-rate   | 厂商给定倍率边界     | 不核实测试条件和持续/脉冲定义 |
| 循环寿命 | 容量/内阻随使用变化  | 只以容量判断健康              |

峰值负载时可用简化模型：

$$
V_{load}\approx V_{oc}-I R_{pack}
$$

低温、老化和高荷电状态变化会改变 $R_{pack}$。低电量保护必须考虑负载回弹，不能只使用瞬时电压阈值。

### 3.2 BMS 不等于飞行能量管理

BMS 负责电芯保护、采样、均衡和安全边界；飞控还需估计任务剩余能量、返航和降落所需功率。保护板突然切断输出对飞行器可能比受控降落更危险，因此电池包、BMS 和飞控策略要协同设计。

### 3.3 电源树设计

- 给出稳态、峰值、启动浪涌和短路状态。
- 评估主功率换相噪声如何耦合到 IMU、GNSS、磁力计和相机。
- 关键电源包含欠压、过压、过流、反接、TVS、软启动和热保护。
- 飞控电压/电流测量要做增益、偏置、温漂和相位校准。
- 伴随计算机突发负载不能使飞控复位。

## 四、飞控 MCU 选型

### 4.1 典型资源

- CPU：Cortex-M4/M7 等，关注 FPU、DSP、cache 和最坏执行时间。
- SRAM：估计器、消息、日志缓冲、网络栈和 DMA 都消耗 RAM。
- Flash：固件、Bootloader、参数默认值和双镜像需求。
- 外设：多个 SPI/UART/CAN、定时器、SDMMC、USB、以太网。
- 安全：独立看门狗、内存保护、ECC/Parity、安全启动和真随机数。

STM32F4/F7/H7 在开源飞控中常见，是生态和外设组合的结果，不代表所有项目必须选择它们。i.MX RT 等高性能 MCU 适合需要更高算力/接口的实时系统。RISC-V MCU 可用于研究或特定产品，但应优先核查工具链、调试、DSP/FPU、RTOS、驱动和长期供货成熟度。

### 4.2 F4、F7、H7 的学习性比较

| 维度     | F4 类                | F7 类            | H7 类                                |
| :------- | :------------------- | :--------------- | :----------------------------------- |
| 学习价值 | 资源受限，易理解取舍 | 性能与复杂度平衡 | 高性能、cache/DMA/内存问题更突出     |
| 常见用途 | 基础/竞速飞控        | 中高阶飞控       | 复杂估计、更多 IO、网络和日志        |
| 主要风险 | Flash/RAM 紧张       | cache 和资源规划 | 多电源域、cache 一致性、热和复杂 BSP |

具体容量和频率随子型号变化，选型必须回到该型号最新数据手册、参考手册和勘误表。

## 五、伴随计算 SoC 与 AI 芯片

### 5.1 计算单元角色

| 单元 | 擅长                       | 不擅长/风险                |
| :--- | :------------------------- | :------------------------- |
| CPU  | 控制流、协议、通用算法     | 大规模卷积效率和功耗       |
| GPU  | 并行视觉、深度学习、图形   | 内存搬运、功耗、调度抖动   |
| NPU  | 支持算子的低功耗推理       | 算子兼容、量化、编译器锁定 |
| DSP  | 信号、向量、低延迟处理     | 工具链和开发门槛           |
| ISP  | 去噪、去马赛克、曝光、颜色 | 黑盒调参和传感器适配       |

### 5.2 候选生态

- NVIDIA Jetson：CUDA/视觉/AI 生态丰富，适合研究和高算力，但需严肃处理重量、功耗、热和供应版本。
- NXP i.MX 8M Plus：Cortex-A53、M7、ISP 和 NPU 组合，适合嵌入式视觉/机器人边缘计算。
- Qualcomm/RB 系列、TI TDA4、各类 ARM NPU SoC：可按视频输入、算子、功耗、BSP 和产品生命周期评估。
- 树莓派/通用 SBC：适合教育与原型，但实时性、连接器、存储和工业环境需额外加固。

“TOPS”不能单独决定选型。应使用真实模型测试端到端延迟、预处理、内存、温升、降频、精度变化和功耗。

## 六、IMU

### 6.1 组成和指标

IMU 通常包含三轴陀螺仪和三轴加速度计。重要指标包括噪声密度、零偏稳定性、温度系数、量程、带宽、输出率、交叉轴、振动整流误差、启动时间和同步能力。

### 6.2 数据链

```text
MEMS 敏感结构
  -> 模拟前端/ADC
  -> 片内数字滤波与 FIFO
  -> SPI/I²C 传输
  -> 驱动读取与时间戳
  -> 旋转、标度、偏置、温度补偿
  -> 降采样/滤波
  -> 估计器与控制器
```

每一层都可能引入延迟。FIFO 数据的“读取时刻”不等于“采样时刻”，应使用数据就绪、硬件时间戳或经过校准的延迟模型。

### 6.3 常见器件学习样本

Bosch BMI088 强调抗振和无人机/机器人应用；TDK ICM-42688-P 提供高性能六轴测量、可配置滤波和高速 SPI。这里的用途是学习数据手册和驱动设计，不构成项目选型结论。量产选型还需验证批次、封装应力、焊接、温漂、供货和实机振动。

### 6.4 冗余 IMU

多 IMU 可以检测单器件故障，但共用电源、时钟、总线、安装位置或同一振动源会形成共因故障。冗余还需要投票/选择逻辑、不同延迟对齐、健康评分和切换瞬态处理。

## 七、其他导航传感器

### 7.1 气压计

通过气压变化估算相对高度，低频有价值，但受天气、温度、桨流、机壳压力和动态压影响。需要泡棉/腔体设计、热隔离和与 GNSS/测距融合。

### 7.2 磁力计

测量地磁方向，可约束航向，但对电机电流、铁磁材料、螺钉、扬声器和环境钢结构敏感。校准不仅是“画八字”，还要评估软铁/硬铁、安装方向和随油门变化的干扰。

### 7.3 GNSS/RTK

GNSS 提供全球位置和速度；多频、多星座和 RTK 可提高精度，但城市峡谷、多径、遮挡、干扰和欺骗仍是风险。RTK 的厘米级固定解不等于连续可靠，必须使用解状态、卫星几何、残差、年龄和创新检查。

### 7.4 光流与测距

光流提供图像平面运动，需要距离将像素运动转成地面速度；ToF/LiDAR/超声提供近地高度。弱纹理、光照、反射率、透明物、水面、倾斜地面和量程外都可能导致退化。

### 7.5 相机和 LiDAR

相机需关注快门类型、曝光、动态范围、帧率、时间戳、同步、镜头和标定稳定性。LiDAR 需关注量程、视场、点频、扫描方式、反射率、阳光、雨雾和运动畸变。

## 八、接口与总线硬件

| 接口       | 典型用途            | 优势                   | 关键风险                         |
| :--------- | :------------------ | :--------------------- | :------------------------------- |
| SPI        | 高频 IMU、Flash     | 全双工、高速、时序可控 | 片选、布线、DMA、总线占用        |
| I²C        | 低速传感器          | 引脚少、生态广         | 上拉、电容、锁死、地址冲突       |
| UART       | GNSS、遥测、RC      | 简单、点对点           | 电平、波特率、帧边界、无原生时钟 |
| CAN/CAN FD | ESC、智能节点       | 差分、仲裁、诊断       | 终端、电气拓扑、总线负载、身份   |
| USB        | 调试、相机、存储    | 高带宽、通用           | 连接可靠性、枚举、供电和 EMI     |
| Ethernet   | 伴随计算、相机、HIL | 高带宽、网络化         | 协议栈、时延抖动、连接器重量     |
| MIPI CSI-2 | 相机到 SoC          | 高吞吐、低引脚         | SI、时钟、驱动和传感器适配       |

## 九、原理图与 PCB 评审清单

- 每个电源域的输入范围、峰值电流、启动时序、保护和测点。
- IMU 供电噪声、地参考、安装位置、热源距离和机械应力。
- 高 di/dt 功率回路与敏感模拟/时钟/GNSS 的隔离。
- 晶振、复位、Boot 配置、SWD/JTAG、量产测试点。
- SPI/I²C/CAN/UART 电平、电阻、ESD、终端和连接器定义。
- SD 卡/Flash 的掉电完整性和日志写入峰值。
- USB/Ethernet/MIPI 的阻抗、回流路径和连接器寿命。
- 反接、短路、单路稳压器失败是否导致不可控推力。
- 版本号、序列号、校准数据和安全密钥的生产写入流程。

## 十、本章实践与验收

1. 从官方数据手册比较两款 IMU，建立统一指标表并标出不可直接比较项。
2. 为一块飞控画出 MCU、三 IMU、气压计、GNSS、SD、CAN 和电源的资源分配。
3. 为伴随计算任务测量真实端到端推理延迟，而非只记录模型运算时间。
4. 建立电池从满电到低温低电的电压下陷模型，并设计分级告警。
5. 对原理图完成一次“单点失效如何传播”的红线审查。
