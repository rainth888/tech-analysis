# 机型、任务载荷、产品化与量产

## 一、从任务而不是芯片开始

产品定义先回答：谁在何种环境、以何种资质、完成什么任务、允许多大风险和成本。随后才推导机型、载荷、航时、链路、定位、算力和法规类别。

### 1.1 任务需求模板

| 维度 | 需要量化的问题                           |
| :--- | :--------------------------------------- |
| 任务 | 面积/线路/目标、频次、成功标准           |
| 环境 | 温度、海拔、风、雨尘、光照、电磁、GNSS   |
| 飞行 | 距离、高度、速度、航时、起降空间、备降   |
| 载荷 | 重量、功耗、视场、精度、稳定和数据量     |
| 通信 | 覆盖、时延、带宽、失联自治、频段         |
| 安全 | 人员/财产暴露、冗余、降级、应急          |
| 运维 | 电池周转、维修、校准、升级、日志、机队   |
| 合规 | 分类、登记、运行识别、空域、人员、无线电 |

## 二、机型选择

### 2.1 多旋翼

适合悬停、近距巡检、影像和狭小起降；缺点是航时/效率和单电机故障能力。四、六、八旋翼的冗余需结合几何、质量、控制分配和实际剩余推力判断，不能只按电机数量宣传。

### 2.2 固定翼

适合测绘、长航线和高效率任务；需要起降场/弹射回收或其他系统，低速/失速和空速系统关键。

### 2.3 复合翼 VTOL

适合既需垂起又需长航时的任务，但结构、执行器、转换控制、维护和验证成本显著增加。应证明任务收益足以覆盖复杂性。

### 2.4 系留平台

可持续供电/通信，适合固定区域观察，但缆线质量、拖曳、缠绕、地面电源、雷电和应急下降成为新风险。

## 三、任务载荷

### 3.1 可见光成像

选择传感器、镜头、焦距、快门、云台和编码。将地面采样距离、视场、航高、速度、曝光和运动模糊联合计算。

### 3.2 红外热成像

关注分辨率、NETD、温漂、标定、镜头材料、辐射测温条件和可见光配准。环境反射、发射率和距离会影响测温，不能把彩色伪彩图当绝对故障证据。

### 3.3 多光谱/高光谱

用于农业和遥感，要求波段、辐射定标、光照参考、几何配准和数据处理链。平台姿态/曝光同步影响拼接和指数计算。

### 3.4 LiDAR/测绘

系统精度由 GNSS/INS、LiDAR、时间同步、杆臂/安装角、扫描几何和后处理共同决定。单个传感器标称精度不能代表点云绝对精度。

### 3.5 其他民用载荷

通信中继、环境传感、搜救照明、公开合规物流等。所有载荷都要分析质量、质心、功耗、EMI、热、气动、释放/运动机构和失效安全。

## 四、系统预算

### 4.1 质量预算

按结构、推进、电池、航电、通信、载荷、线束/紧固和设计裕量分项。称重实测后回填，不让“其他”持续吞掉裕量。

### 4.2 能量预算

分别计算悬停/巡航、机动、低温、逆风、返航和老化电池。可用任务时间扣除起降、预热、等待和安全余量。

### 4.3 算力和热预算

CPU/GPU/NPU、ISP、内存带宽、摄像头、编码、无线和存储并发测量。高温稳态下验证降频后仍满足最坏延迟。

### 4.4 通信和存储

按消息频率、大小、协议开销和峰值计算；视频按最坏场景和码率；日志要支撑事故前后关键数据且不能拖垮实时系统。

## 五、可靠性与冗余

冗余价值来自独立检测和可用降级，不是器件数量。双 IMU 同电源同总线、双 GNSS 同天线环境、双计算进程同 OS 都可能共因失败。

评估：故障率、检测覆盖、切换时间、瞬态、剩余控制能力、质量功耗成本和维护误装风险。

## 六、DFM、DFA 与 DFT

- DFM：器件、PCB、结构适合稳定制造，公差和工艺可实现。
- DFA：装配方向、防错、紧固、线束和校准步骤清楚。
- DFT：电源、时钟、通信、传感器、存储、射频和安全功能可自动测试。

生产测试至少包含板级电源/短路、MCU/存储、传感器 ID/噪声、接口、射频、序列号/密钥、校准和整机电机方向。测试治具和软件也要版本化。

## 七、供应链与生命周期

- 关键 MCU、IMU、GNSS、PMIC、MOSFET 和连接器有生命周期和替代风险。
- 第二来源不是封装相同即可替换，需要驱动、噪声、温漂、时序和认证回归。
- 反假货、来料追溯、批次漂移和固件兼容需纳入质量系统。
- 开源上游、安全漏洞和工具链停止支持也属于供应链风险。

## 八、校准和出厂

定义每架机唯一身份、硬件版本、传感器序列、校准参数、工装版本和结果。出厂校准后做独立验证，防止算法对同一数据自证。维修换件触发相关重校准和功能回归。

## 九、运维和机队

- 电池按循环、内阻、温度和异常记录管理。
- 桨、电机、轴承、结构和防水件有检查/更换周期。
- 固件分批发布、灰度、回滚和兼容门禁。
- 飞行日志自动上传需考虑隐私、带宽、授权和保留周期。
- 异常机隔离，不能通过清日志或重新校准直接放行。

## 十、验收指标示例

| 类别 | 指标示例                     | 证据                 |
| :--- | :--------------------------- | :------------------- |
| 飞行 | 悬停误差、航迹误差、抗风     | 标准场景多次日志     |
| 能量 | 任务时间、最低电压、余量     | 新旧/低温电池测试    |
| 感知 | 检出/漏检、定位漂移、延迟    | 分层数据集和实飞日志 |
| 通信 | P95/P99 延迟、最长断链、恢复 | 衰减/干扰/遮挡测试   |
| 安全 | 故障检测和受控动作           | 注入测试与视频/日志  |
| 环境 | 高低温、振动、雨尘后性能     | 标准/项目定义试验    |
| 量产 | 首次通过率、校准分布、追溯   | MES/测试数据库       |

## 十一、本章实践与验收

1. 为巡检或测绘任务完成任务→机型→载荷→预算→安全的选型报告。
2. 建立质量、功率、算力和通信四张预算表，保留裕量。
3. 对一个“冗余”设计做共因故障评审。
4. 设计板级和整机生产测试项目及限值来源。
5. 写出换 IMU/电机/相机后必须回归的测试集合。
