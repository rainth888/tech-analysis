# 飞行动力学、控制算法与飞控工程

## 一、飞控的职责边界

飞控不是 PID 集合，而是包含状态、模式、约束和故障处理的实时闭环系统。它接收传感器和操作者/任务期望，估计当前状态，生成可实现的轨迹，计算期望力与力矩，分配给执行器，并持续判断数据和执行器是否可信。

```text
操作者/任务
  -> 模式与轨迹生成
  -> 位置环 -> 速度环 -> 姿态环 -> 角速度环
  -> 力/力矩命令 -> 控制分配 -> 执行器
                         ^
传感器 -> 状态估计 ------|
安全状态机 -> 限幅/接管/返航/降落/终止
```

## 二、建模的层次

### 2.1 从简单模型开始

| 模型         | 状态/对象                  | 用途                | 忽略项             |
| :----------- | :------------------------- | :------------------ | :----------------- |
| 一维高度     | 高度、速度、推力           | PID、饱和、重力补偿 | 姿态、风、桨耦合   |
| 单轴姿态     | 角度、角速度、力矩         | 串级环、带宽        | 三轴耦合、平移     |
| 六自由度刚体 | 位置、速度、姿态、角速度   | 完整飞控仿真        | 柔性、复杂气动     |
| 执行器模型   | 电机/舵机动态、限幅、时延  | 真实响应和稳定裕度  | 精细电磁/流体细节  |
| 高保真模型   | 桨流、气动表、结构、传感器 | 极限与 HIL          | 成本高、参数难获取 |

模型不是越复杂越好。应与问题匹配，并通过台架或日志辨识关键参数。

### 2.2 多旋翼状态和输入

典型状态包括位置 $\mathbf{p}$、速度 $\mathbf{v}$、姿态 $\mathbf{R}$ 或 $\mathbf{q}$、角速度 $\boldsymbol{\omega}$。输入可抽象为总推力 $T$ 和三轴力矩 $\boldsymbol{\tau}$，再通过控制分配映射到各执行器。

### 2.3 执行器不是瞬时理想量

电机/桨有时间常数、死区、最小转速、非线性、饱和和电压依赖。忽略执行器动态会高估可用控制带宽。电池电压下降时，同样命令对应的推力可能改变，需靠 ESC/飞控补偿和参数化模型处理。

## 三、串级控制

### 3.1 为什么分环

角速度环最快，直接抑制旋转；姿态环在其外侧生成角速度期望；速度和位置环更慢。内环必须比外环快，外环才能把内环近似为可控执行器。

典型数量级因机型和固件而异，不能照抄频率。设计应满足：传感器采样与滤波足够快、计算/执行延迟可控、结构模态不在有效闭环带宽内、执行器有余量。

### 3.2 PID 的物理意义

$$
u=K_Pe+K_I\int e\,dt+K_D\frac{de}{dt}+u_{ff}
$$

- P：根据当前误差产生恢复作用，过大可导致振荡。
- I：消除持续偏差，如质心不平衡或恒风；饱和时需抗积分饱和。
- D：对误差变化提供阻尼，但对噪声敏感，工程上常对测量或滤波后量求导。
- 前馈：根据期望变化提前给出动作，减少只靠误差追赶的滞后。

### 3.3 设定值整形

操作者或规划器给出的阶跃可能要求无限加速度。应限制速度、加速度、jerk、倾角、偏航速率和推力，并考虑不同模式切换时设定值连续。

## 四、角速度与姿态控制

### 4.1 角速度环

输入是期望角速度，输出是三轴力矩或归一化控制量。重点观察：期望与实测跟踪、相位、噪声、输出饱和和各轴耦合。

### 4.2 姿态误差

小角度可用欧拉角差直观处理，但大姿态机动应在旋转群/四元数上定义误差，避免绕行和奇异。姿态控制输出角速度期望，同时限制最大倾角和偏航行为。

### 4.3 偏航

常规四旋翼偏航依赖反扭矩差，能力通常弱于滚转/俯仰，并受桨、电机、机架和推力水平影响。高总推力时可能没有足够偏航余量，控制分配需要优先级策略。

## 五、位置、速度和高度控制

### 5.1 位置到推力向量

位置误差产生速度期望，速度误差产生期望加速度，再结合重力和质量形成期望总推力方向与大小。总推力方向决定滚转/俯仰，航向期望决定剩余自由度。

### 5.2 高度

高度源可能来自气压、GNSS、测距或视觉。接近地面时地效、桨流和测距跳变会影响控制。着陆状态机需要下降率、接地检测、反弹处理和停桨条件。

### 5.3 风与倾角限制

强风下保持位置需要倾斜，垂直分量减少，必须提高总推力。倾角、推力、电池和结构限制共同决定最大可抗风能力。位置环不能无限积分追逐不可实现目标。

## 六、控制分配与混控

### 6.1 基本形式

$$
\mathbf{u}_{body}=\mathbf{B}\mathbf{f}_{act}
$$

$\mathbf{B}$ 由执行器位置、推力方向和反扭矩构成。求解 $\mathbf{f}_{act}$ 时要满足每个执行器上下限、变化率和故障状态。

### 6.2 饱和策略

当所有轴需求无法同时满足时，要明确优先级。常见思路是优先保持总推力和滚转/俯仰，允许牺牲部分偏航；具体策略取决于机型和安全目标。简单逐通道裁剪会扭曲力矩方向并导致积分器错误累积。

### 6.3 VTOL 和冗余机型

多余执行器可通过伪逆、加权最小二乘或优化分配；权重随空速、转换状态、舵面效能和故障变化。必须避免分配矩阵病态、执行器抖动和模式切换不连续。

## 七、固定翼控制

- 横滚/航向：副翼控制滚转，方向舵协调侧滑；航向控制通常经由滚转角。
- 俯仰/高度：升降舵、空速、迎角和推力耦合。
- 总能量控制：通过油门和俯仰在势能与动能之间分配，避免只追高度而失速。
- 起飞、爬升、巡航、盘旋、进近和着陆是不同状态，具有各自门限和中止逻辑。

## 八、滤波与控制的联合设计

### 8.1 延迟预算

```text
MEMS/模拟滤波
 + 片内数字滤波/FIFO
 + 总线与驱动
 + 估计器
 + 控制计算
 + 输出协议
 + ESC/电机/桨
 = 命令到实际力矩的总延迟
```

每增加滤波都可能增加相位滞后。先消除机械振动，再选采样率和抗混叠，再设计低通/陷波，最后调控制增益。

### 8.2 动态陷波

使用 ESC 转速遥测或频谱估计跟踪基频及谐波。需验证遥测丢失、错误极对数、转速突变和多个电机频率交叉时的行为。

## 九、系统辨识和调参

### 9.1 辨识对象

执行器时间常数、推力曲线、惯量、控制延迟、结构共振和气动阻尼。辨识输入必须安全、可观测且不超出包线。

### 9.2 调参顺序

1. 机械、电源、方向、标定和传感器健康通过。
2. 配置正确滤波，确认无饱和/混叠。
3. 从角速度内环开始，逐轴、小幅、可回退。
4. 再调姿态、速度、位置和任务层。
5. 每次变更只改变有限变量，保留日志和版本。

### 9.3 日志判据

看期望/实测、误差、控制输出、积分、饱和、电机差异、振动、延迟和模式事件。仅凭手感或视频无法区分增益、滤波、结构和估计问题。

## 十、模式、状态机与控制权

### 10.1 控制权来源

可能来自遥控器、任务、伴随计算、返航、地理围栏或故障保护。系统必须有唯一仲裁规则，明确优先级、超时、切入条件、退出条件和设定值连续性。

### 10.2 解锁和地面状态

解锁前检查传感器、估计、参数、RC、任务、电池、存储和安全开关。上电、解锁、起飞、飞行、着陆、落地后停桨应是显式状态，不能只以油门值猜测。

### 10.3 Failsafe

失联、低电、定位丢失、航向异常、执行器故障、地理围栏和伴随计算超时的最佳动作不同。返航依赖位置、航向、能量和路径安全；这些条件不可信时，返航可能不是安全选择。

## 十一、进阶控制路线

| 方法        | 学习价值                  | 适用问题             | 工程注意               |
| :---------- | :------------------------ | :------------------- | :--------------------- |
| LQR/LQG     | 状态空间和权衡            | 线性化多变量控制     | 模型与工作点、约束     |
| MPC         | 显式处理预测与约束        | 轨迹、VTOL、避障耦合 | 算力、可行性、超时备份 |
| 几何控制    | 直接在 SO(3)/SE(3) 上处理 | 大姿态机动           | 数学门槛、执行器约束   |
| 鲁棒/自适应 | 参数不确定和扰动          | 载荷变化、风         | 稳定证明、边界与调试   |
| 增量控制    | 借助测量减少模型依赖      | 高动态、模型不确定   | 导数噪声、延迟         |

进阶算法只有在基线 PID/估计/执行器和验证设施可靠后才有比较意义。
