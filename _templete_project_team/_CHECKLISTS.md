# _CHECKLISTS.md —— 稳定功能清单与回归冻结注册表

> 本文件是项目唯一权威的稳定功能（`🔒 STABLE`）与交叉影响清单（AR 与 QA 共同维护，修改需获取 `task-metadata` 租约）。
> - 任何功能只有经 QA 独立测试通过、PO 业务验收通过，并由**真人明确声明稳定**后，方可标记为 `🔒 STABLE`。
> - 一旦标记为 `🔒 STABLE`，其登记的源码、契约、迁移脚本与配置范围即刻冻结；未经真人书面批准并将状态改为 `⚠️ CHANGE_APPROVED`，任何角色不得修改或削弱。

## 状态定义

| 状态                 | 含义                                                        |
| -------------------- | ----------------------------------------------------------- |
| `🚧 DEVELOPING`      | 正在开发或联调中                                            |
| `🧪 TESTING`         | 已部署测试环境，QA 正在独立测试                             |
| `🔒 STABLE`          | 已通过 QA 测试、PO 验收并获真人确认稳定，代码与契约范围冻结 |
| `⚠️ CHANGE_APPROVED` | 经真人批准允许在限定范围内修改，修改后必须执行全量关联回归  |
| `🔄 REVALIDATING`    | 修改已完成，正在由 QA 执行回归测试与 PO 复验                |
| `🗑️ DEPRECATED`      | 已由新功能替代并经变更单（CR）批准下线                      |
