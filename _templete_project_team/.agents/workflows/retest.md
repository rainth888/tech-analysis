# 标准协作剧本：QA 复测缺陷并裁决关闭（/retest IS-xxx）

1. **QA 专用**。读取 `IS-xxx`，确认其状态为 `待复测`，且已收到 OPS 针对包含该修复的新版本部署交接单（含新构建号与提交号）。
2. 核对开发人员在单据中填写的“根因说明、修改文件、防止回归的单元测试证据”是否完整。
3. 在测试环境按原复现步骤复测，并执行关联回归用例：
   - 复测与回归均通过：在单据“复测记录”栏填写复测版本号与结果，将状态改为 `已关闭`；
   - 复测未通过或引发回归问题：状态改回 `修复中`，**返工次数 +1**，附上新的失败证据；返工 ≥ 3 次时同步通知 PM 升级处理。
4. 同步更新 `docs/collab/BOARD.md`。
