# 标准协作剧本：QA 登记独立测试缺陷单（/defect <责任角色> <缺陷摘要>）

1. **QA 专用**。在 `docs/collab/issues/` 下创建 `IS-{三位递增编号}-{缺陷摘要}.md`（类型=`缺陷`，严重级别=`致命 | 严重 | 一般 | 提示`）。
2. 必填项：发现环境（`test / staging`）、可追溯版本号（构建号 + Git 提交号）、关联用例 `TC-xxx` 与需求 `FR/US/API`、前置条件与测试账号、精确复现步骤、期望结果、实际结果、客观证据（接口报文 / 截图路径 / 日志 `traceId`）、初判责任角色（`BE / FE / AI / OPS`）。
3. 在 `docs/collab/BOARD.md` 的“问题与缺陷单表”及“缺陷看板”登记（初始状态=`新建`）。
