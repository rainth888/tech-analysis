# 标准协作剧本：跨角色正式交接（/handoff <接收角色> <主题>）

1. 核对本次产出的所有文件均已保存且通过自检命令。
2. 在 `docs/collab/handoff/` 下创建 `HO-{三位递增编号}-{简述}.md`，严格填写：
   - 发起角色、接收角色、日期、关联编号（`Txx` / `FR-xx` / `API-xx` / 版本号）；
   - 交接类型：`交付` / `接口就绪` / `联调完成待测试` / `版本已部署` / `测试通过可验收` / `通知`；
   - 交付文件路径与关键说明；
   - 验证证据（测试命令输出、健康检查结果、构建号与 Git 提交号）；
   - 接收方下一步需要执行的具体动作与已知限制；
   - 接收确认栏（默认状态：`待接收`）。
3. 获取 `collab-board` 租约，在 `docs/collab/BOARD.md` 的“交接单表”追加一行，然后释放租约。
