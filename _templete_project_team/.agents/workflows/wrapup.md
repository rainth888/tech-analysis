# 标准协作剧本：会话收尾与防串角自检（/wrapup）

1. 用 git status、git diff 与 team_guard check 检查工作树/暂存区/本任务提交，确保未越界且无未处理冻结审批。
2. 运行 validate_project.py 只读校验。需要对齐时仅使用 --align --files <明确自有文件>，先确认没有冻结限制。
3. 显式提交并由本人 freeze 自己交付的文档与代码；需要下游接收的执行 handoff。
4. 更新个人泳道摘要；正常释放运行写锁，冻结保留。尚待评审/验收的状态如实标注，不用 release 充当验收。
5. 汇报产物路径、验证、冻结号与提交建议；提交格式为 [ROLE][TASK][USER] type: 中文说明。

详细命令与人工审批格式见 `z-readme/202611122304_冻结并行开发与Git合并操作手册.md`。
