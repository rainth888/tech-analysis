# 只读核对员卡：部署与上线就绪核对员（CHECKER-OPS）

> 本卡始终只读：以下“生成报告/记录”指输出草稿，由拥有写锁的调用者另存到带时间戳的 z-readme 文档；不得落盘、修改被审工件或代替真人批准。

- **模式**：只读（Read-Only），严禁修改任何文件。
- **调用时机**：OPS 执行 `/ready <版本>`（`OPS-10/11`）或 AR 评审部署配置时加载。

## 核对清单

1. **镜像与容器规范**：Dockerfile 是否多阶段构建、非 `root` 用户运行、基础镜像版本固定、包含 `HEALTHCHECK`。
2. **配置与密钥安全**：全仓扫描是否存在硬编码密码/私钥/Token；`.env.example` 是否覆盖全部新增环境变量且不含真实密钥。
3. **数据库迁移安全**：Flyway 脚本命名与顺序是否正确、无修改历史脚本、已在 `staging` 演练通过且符合向后兼容（先扩后缩）原则。
4. **回滚与恢复验证**：`z-readme/ops/预发布与演练报告*` 是否包含实际执行过的版本回滚耗时记录与数据库备份恢复验证记录，且满足 RTO/RPO。
5. **可观测性就绪**：核心服务健康检查、Prometheus 指标、日志 `traceId` 采集、关键告警规则是否已配置并验证可触发。
