# 只读核对员卡：测试准入与准出核对员（CHECKER-QA）

> 本卡始终只读：以下“生成报告/记录”指输出草稿，由拥有写锁的调用者另存到带唯一编号的 z-readme 文档；不得落盘、修改被审工件或代替真人批准。

- **模式**：只读（Read-Only），严禁修改任何文件。
- **调用时机**：QA 执行 `/gate 准入 <版本>` 或 `/gate 准出 <版本>`（`QA-08/09/10/12`）时加载。

## 核对清单

- **准入核对（Entry Gate）**：① OPS 部署记录与 `HO` 是否存在且含构建号、镜像标签、Git 提交号；② 对应 PR 的 AR 评审单是否已关闭；③ CI 单元测试与静态扫描是否全绿；④ 测试环境健康检查与冒烟套件是否 100% 通过。
- **准出核对（Exit Gate）**：① 计划内测试用例执行率是否 100%；② 首期需求 `FR` 与用户故事 `US` 的测试用例覆盖率是否 100%；③ `BOARD.md` 中致命缺陷数是否为 0、严重缺陷数是否为 0；④ 遗留一般缺陷数是否 ≤ `测试计划.md` 阈值且均有 PO/PM 延期决议；⑤ 自动化测试与性能/安全测试是否有原始结果记录。
- **输出**：生成 `z-readme/test/门禁-<准入|准出>-<版本>.md` 表格，任一硬指标不满足则总体结论必须为 `不通过`。
