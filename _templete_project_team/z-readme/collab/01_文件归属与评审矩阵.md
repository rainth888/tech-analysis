## 必需评审

- 需求/业务验收标准：PO 主责，AR、QA 审查。
- 架构/权限策略/协作工具：AR 主责，PM、相关技术角色审查；权限或冻结规则改变由真人批准。
- API 契约：BE/AR 主责，FE、QA、AR 审查；冻结后任意变更须真人解冻。
- 后端/前端/AI 实现：对应开发者主责，AR 技术评审，QA 独立测试；关键业务由 PO 验收。
- 测试与部署：QA/OPS 主责，AR 与相关角色交叉审查；不能修复后自签独立通过。
- main 精确候选与生产发布：所需质量门禁通过，并按真实用户授权执行。

独立评审者是另一个执行主体，不仅是把自己的 role_id 改成 reviewer。同一行多个 CODEOWNERS 只提供评审路由，不代表上述全部必审角色都已批准。本人冻结交付快照不需要等所有评审完成；评审完成决定合并/验收，不决定是否保护已交付成果。
