# 02 各岗位角色项目文件夹与工作空间规范

> **多人协作前置规则（复制提示词时一并加载）**：先按 AGENTS.md 声明 user_id、actor_id、role_id、task_id、lane_id；同角色多人各用独立分支/worktree，先领取不相交的文件与资源。自己的文档和代码在自检提交后分别冻结；任何冻结修改（含兼容变化、格式化）先有明确接口/功能干涉依据及真人批准，批准可指定其他用户/角色接手，无需原角色回来。冻结单据的回复另建记录。所有新文档放 z-readme/ 并使用时间戳与人员标识；固定示例名是内容类型，不是免除命名要求。运行锁以共享协调中心为准，Markdown 摘要不作为锁。具体命令见 `z-readme/202611122304_冻结并行开发与Git合并操作手册.md`。

> **定位**：本文档为团队中的 **8 个岗位角色（7 大核心角色 PM、PO、AR、BE、FE、QA、OPS + 1 个可选扩展角色 AI）** 分别定义其**专属项目文件夹视图、读写权限边界、日常输入/输出文件清单、分支与 Worktree 工作空间约定、角色就位检查单以及违规越界红线**。
> 任何人员或 AI 代理在就任某一角色时，只需对照本章对应小节，即可清楚知道“我该看哪些目录、我只能写哪些目录、我的产出放在哪里”。

## 1. 全项目目录树与角色所有权全景图

```text
<ProjectRoot>/
├─ AGENTS.md                         # 身份、冻结、Git 与授权规则
├─ _STATE.md / _TASKLISTS.md          # 项目阶段摘要与任务池
├─ _STATE_HISTORY.md / _CHECKLISTS.md # 历史与人工验收稳定功能
├─ .agents/
│  ├─ roles/                        # 专业角色和只读核对卡
│  ├─ workflows/                    # 固定协作动作入口
│  └─ parallel/
│     ├─ policy.json                # 唯一机器路径权限配置
│     └─ lanes/TEMPLATE.md          # 仅格式示例，不是运行锁
├─ z-readme/                         # 统一生成文档中心
│  ├─ 00~06_*.md                    # 内置手册，保留原名
│  ├─ YYYYMMDDHHMM_*.md             # 计划、索引、方案与验证报告
│  ├─ roles/<ROLE>/<USER>/           # 个人文档范围，仍须领取
│  ├─ lanes/                        # 个人泳道摘要，不是锁
│  ├─ analysis/ / architecture/ / adr/
│  ├─ design/db/ / api/ / ui/ / ai/
│  ├─ acceptance/ / test/ / ops/ / delivery/
│  └─ collab/                       # 成员、评审矩阵、HO/IS/RV/CR
├─ z-docs/                          # 原始需求输入，只读
├─ z-scripts/                       # 校验、协调工具及回归测试
├─ z-resource/ / z-prototype/        # 媒体与原型工程素材
├─ z-logs/ / z-temps/<LANE>/         # 脱敏原始日志及隔离临时输出
├─ server/                          # BE 业务工程
├─ web/ / mobile/                   # FE；web/e2e/ 为 QA
├─ ai/                              # AI 工程
├─ tests/                           # QA 测试工程
└─ deploy/ / .ci/                   # OPS 部署与未激活 CI 示例
```

运行协调中心位于 Git common dir 下的 team-guard，跨 clone 必须配置同一受控中心。实际文档模板路径见 `z-readme/202611122304_工程文档导航.md`，下列简写表示内容类型；新文件必须加时间戳及人员标识。
