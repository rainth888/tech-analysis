# 02 各岗位角色项目文件夹与工作空间规范

> **定位**：本文档为团队中的 **8 个岗位角色（7 大核心角色 PM、PO、AR、BE、FE、QA、OPS + 1 个可选扩展角色 AI）** 分别定义其**专属项目文件夹视图、读写权限边界、日常输入/输出文件清单、分支与 Worktree 工作空间约定、角色就位检查单以及违规越界红线**。
> 任何人员或 AI 代理在就任某一角色时，只需对照本章对应小节，即可清楚知道“我该看哪些目录、我只能写哪些目录、我的产出放在哪里”。

## 2. 八大岗位角色专属文件夹与工作空间详解

### 2.1 项目经理（`PM`）文件夹与工作空间规范

| 维度             | 规范内容                                                                                                                                                                                                                                             |
| ---------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **角色准则卡**   | `.agents/roles/PM.md`                                                                                                                                                                                                                                |
| **日常必读目录** | `_STATE.md`、`_TASKLISTS.md`、`docs/PLAN.md`、`docs/PROGRESS.md`、`docs/collab/BOARD.md`、`RISKS.md`、`.agents/parallel/lanes/`                                                                                                                      |
| **唯一可写目录** | `_STATE.md`、`_TASKLISTS.md`、`_STATE_HISTORY.md`、`docs/PLAN.md`、`docs/PROGRESS.md`、`docs/collab/TEAM.md`、`BOARD.md`、`RISKS.md`、`度量.md`、`项目总结.md`、`docs/collab/meetings/**`、本人发起的 `HO/IS/CR` 及 `.agents/parallel/lanes/*-PM.md` |
| **所需租约**     | 修改根状态文件与 `PLAN/PROGRESS/BOARD` 时必须获取 `task-metadata` 或 `collab-board` 租约；合并分支时获取 `git-index` 租约                                                                                                                            |
| **分支约定**     | 文档与计划更新在 `develop` 或 `docs/p*-pm`；负责将已通过评审/测试/验收的角色分支合并入 `develop` 及发布时合并 `release/*`                                                                                                                            |
| **绝对禁区**     | `docs/analysis/`、`docs/architecture/`、`docs/design/`、`server/`、`web/`、`mobile/`、`ai/`、`tests/`、`deploy/`                                                                                                                                     |
