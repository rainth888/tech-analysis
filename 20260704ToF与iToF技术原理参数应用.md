# ToF / iToF 技术原理、参数体系与行业应用

本文只关注 ToF / iToF 通用技术，不涉及具体项目、具体板卡、具体模组或私有调试信息。

---

## 1. ToF 是什么

ToF 是 Time of Flight，意思是“飞行时间”。它通过主动发射光，再接收目标反射回来的光，计算光从发射到返回所对应的距离。

核心思想：

```text
发射红外光 → 光照到物体 → 物体反射 → 传感器接收 → 计算距离
```

光速已知，因此只要能测出光传播相关的时间或相位，就能得到距离。

常见 ToF 摄像头通常输出：

| 输出数据          | 含义                                 |
|-------------------|--------------------------------------|
| Depth / Distance  | 每个像素对应的距离                   |
| Amplitude         | 每个像素接收到的主动光反射强度       |
| Confidence        | 深度值可信度                         |
| Point Cloud       | 由深度图和相机内参转换得到的三维点集 |
| IR Image          | 红外强度图或灰度图                   |

---

## 2. ToF 的主要类型

ToF 主要分为 dToF 和 iToF。

| 类型   | 全称          | 测距方式                   | 常见形态                         |
|--------|---------------|----------------------------|----------------------------------|
| dToF   | Direct ToF    | 直接测量光脉冲往返时间     | LiDAR、SPAD 阵列、激光测距       |
| iToF   | Indirect ToF  | 测量调制光发射/接收相位差  | 深度摄像头、手机 ToF、3D 相机    |

### 2.1 dToF

dToF 发射短光脉冲，并测量光从发射到返回的时间。

距离公式：

```text
distance = c * Δt / 2
```

其中：

| 符号 | 含义                         |
|------|------------------------------|
| `c`  | 光速                         |
| `Δt` | 光往返时间                   |
| `/2` | 光走了往返路程，距离取一半   |

dToF 优点是测距直观、可做较远距离；缺点是对高速计时电路要求高。

### 2.2 iToF

iToF 不直接测量极短时间，而是发射连续调制红外光，通过接收信号和发射信号之间的相位差计算距离。

简化理解：

```text
发射信号: 正弦/方波调制红外光
接收信号: 被物体反射后延迟返回
相位差:   延迟对应的相位偏移
距离:     由相位差换算
```

iToF 更适合做成二维深度摄像头，因此在消费电子、机器人、智能硬件中很常见。

## 3. iToF 的相位测距原理

iToF 通常使用调制频率为 `f` 的红外光。调制周期为：

```text
T = 1 / f
```

如果接收光相对发射光延迟了时间 `Δt`，则会产生相位差：

```text
phase = 2π * Δt / T
```

距离近似为：

```text
distance = c * Δt / 2
```

合并后可理解为：

```text
distance ∝ phase / modulation_frequency
```

iToF 传感器通常不会只采一张图，而是采集多个相位采样，例如：

```text
0° / 90° / 180° / 270°
```

通过这些采样计算：

| 计算结果    | 含义                                           |
|-------------|------------------------------------------------|
| Phase       | 相位差，决定距离                               |
| Amplitude   | 调制信号强度，表示主动光回波                   |
| Offset      | 环境光、暗电流或系统偏置                       |
| Confidence  | 深度可信度                                     |

典型四相位解算形式可以抽象为：

```text
phase = atan2(Q3 - Q1, Q0 - Q2)
amplitude = sqrt((Q3 - Q1)^2 + (Q0 - Q2)^2)
```

这里 `Q0/Q1/Q2/Q3` 是不同相位下采集到的信号。

## 4. 无歧义距离与多频 iToF

iToF 测的是相位，而相位是周期性的。超过一个调制周期后，相位会绕回，这会带来距离歧义。

无歧义距离约为：

```text
Rmax = c / (2 * f)
```

其中 `f` 是调制频率。

调制频率越高：

| 影响           | 说明                         |
|----------------|------------------------------|
| 距离分辨率     | 通常更好                     |
| 无歧义距离     | 更短                         |
| 抗噪声特性     | 与系统设计相关               |

调制频率越低：

| 影响           | 说明                         |
|----------------|------------------------------|
| 无歧义距离     | 更长                         |
| 近距离精度     | 可能下降                     |

因此很多 iToF 系统使用双频或多频：

| 方法       | 目的                                         |
|------------|----------------------------------------------|
| 高频       | 提高近距离精度                               |
| 低频       | 扩大无歧义范围                               |
| 多频融合   | 同时兼顾精度和距离范围                       |

## 5. ToF 常见参数体系

ToF 摄像头参数很多，不能只看分辨率。它同时涉及光学、照明、调制、传感器、算法、标定、温度和接口。

### 5.1 深度参数

| 参数                 | 含义                                   | 关注点                             |
|----------------------|----------------------------------------|------------------------------------|
| Depth Resolution     | 深度图分辨率                           | 决定点云密度                       |
| Depth Range          | 有效测距范围                           | 最近/最远可测距离                  |
| Minimum Range        | 最小测距距离                           | 近距离是否过曝或无效               |
| Maximum Range        | 最大测距距离                           | 受照明、反射率、环境光影响         |
| Accuracy             | 绝对距离误差                           | 距离值准不准                       |
| Precision            | 重复测量稳定性                         | 固定目标时抖动大小                 |
| Noise                | 深度噪声                               | 点云是否散                         |
| Fill Rate            | 有效深度点比例                         | 有效点越多，图越完整               |
| Invalid Value        | 无效距离值                             | 软件必须过滤                       |

### 5.2 幅度与置信度参数

| 参数                 | 含义                                   | 关注点                             |
|----------------------|----------------------------------------|------------------------------------|
| Amplitude            | 主动红外回波强度                       | 判断是否收到足够反射光             |
| Confidence           | 深度可信度                             | 用于过滤低可信点                   |
| Min Amplitude        | 最小幅度阈值                           | 太低噪声多，太高有效点少           |
| Saturation           | 饱和状态                               | 饱和点深度可能不可信               |
| Ambient Light        | 环境光强度                             | 强阳光会降低信噪比                 |
| Reflectivity         | 目标反射率                             | 黑色、透明、镜面材质更难测         |

### 5.3 光学参数

| 参数                 | 含义                                   | 关注点                             |
|----------------------|----------------------------------------|------------------------------------|
| FOV                  | 视场角                                 | 决定覆盖范围                       |
| Focal Length         | 焦距                                   | 决定视场角和点云比例               |
| fx / fy              | 以像素为单位的焦距                     | 点云投影必需                       |
| cx / cy              | 光心坐标                               | 点云投影必需                       |
| Distortion           | 镜头畸变                               | 影响点云几何                       |
| IR Filter            | 红外窄带滤光片                         | 抑制环境光                         |
| Baseline             | 发射器和接收器相对位置                 | 影响近距离遮挡和多路径             |

### 5.4 照明与调制参数

| 参数                 | 含义                                   | 关注点                             |
|----------------------|----------------------------------------|------------------------------------|
| VCSEL / LED Power    | 红外发射功率                           | 功率不足幅度低，功率过高发热       |
| Wavelength           | 红外波长，例如 850nm / 940nm           | 影响人眼安全和环境光表现           |
| Modulation Frequency | 调制频率                               | 影响精度和无歧义距离               |
| Duty Cycle           | 占空比                                 | 影响光功率和温升                   |
| Phase Count          | 相位采样数量                           | 影响解算精度                       |
| Integration Time     | 积分时间                               | 影响回波强度和过曝风险             |
| Multi-Frequency      | 多频调制                               | 降低相位歧义                       |

### 5.5 曝光、帧率与动态范围

| 参数                 | 含义                                   | 关注点                             |
|----------------------|----------------------------------------|------------------------------------|
| Exposure             | 曝光/积分时间                          | 影响幅度和深度有效点               |
| Auto Exposure        | 自动曝光                               | 适应不同距离和反射率               |
| Max Exposure         | 最大曝光限制                           | 限制温度和帧率                     |
| FPS                  | 帧率                                   | 影响实时性和运动目标表现           |
| HDR                  | 高动态范围                             | 同时兼顾近处强反射和远处弱反射     |
| Motion Artifact      | 运动伪影                               | 目标运动时相位帧之间不一致         |

### 5.6 标定与补偿参数

| 参数                     | 含义                               | 关注点                             |
|--------------------------|------------------------------------|------------------------------------|
| Intrinsic Calibration    | 内参标定                           | 点云几何是否正确                   |
| Distortion Calibration   | 畸变标定                           | 平面是否弯曲                       |
| Offset Calibration       | 距离零点补偿                       | 绝对距离是否准确                   |
| Wiggling Correction      | 相位非线性补偿                     | 降低周期性距离误差                 |
| Temperature Compensation | 温度补偿                           | 温度变化时距离不漂                 |
| Bad Pixel Map            | 坏点表                             | 去掉异常像素                       |
| Crosstalk Correction     | 串扰补偿                           | 降低窗口/镜头内部反射              |
| Multipath Correction     | 多路径补偿                         | 降低墙角、反光面造成的假距离       |

### 5.7 温度、安全与可靠性参数

| 参数                 | 含义                                   | 关注点                             |
|----------------------|----------------------------------------|------------------------------------|
| Sensor Temperature   | 传感器温度                             | 影响噪声和距离漂移                 |
| Illumination Temp    | 照明驱动或光源温度                     | 影响寿命和安全                     |
| NTC Temperature      | 模组热敏电阻温度                       | 判断整体热状态                     |
| Eye Safety           | 人眼安全等级                           | VCSEL/激光类产品必须关注           |
| Thermal Throttle     | 温度降额策略                           | 过热时降帧率、降功率或停机         |
| Long-Term Drift      | 长时间运行漂移                         | 工业和测量场景必须验证             |

### 5.8 接口与数据格式参数

| 参数                 | 含义                                   | 关注点                             |
|----------------------|----------------------------------------|------------------------------------|
| MIPI / USB / Ethernet| 数据接口                               | 决定集成方式和带宽                 |
| Data Format          | Raw phase / depth / amp / point cloud  | 决定软件处理方式                   |
| Bit Depth            | 位深，例如 10/12/16 bit                | 影响动态范围和精度                 |
| Timestamp            | 时间戳                                 | 多传感器同步需要                   |
| Sync Trigger         | 外部同步触发                           | 多相机或机器人场景重要             |
| Buffering            | 缓冲机制                               | 影响延迟和丢帧                     |

## 6. 点云生成原理

深度图是二维的，点云是三维的。转换需要相机内参。

对于像素 `(u, v)`，深度为 `Z`，相机内参为 `fx, fy, cx, cy`：

```text
X = (u - cx) * Z / fx
Y = (v - cy) * Z / fy
Z = depth
```

其中：

| 坐标 | 含义                         |
|------|------------------------------|
| X    | 左右方向                     |
| Y    | 上下方向                     |
| Z    | 距离摄像头的前后方向         |

点云质量取决于：

| 因素             | 影响                                   |
|------------------|----------------------------------------|
| 深度噪声         | 点云是否发散                           |
| 有效点比例       | 点云是否完整                           |
| 相机内参         | 点云几何是否正确                       |
| 畸变校正         | 平面是否弯曲                           |
| 幅度过滤         | 是否保留大量噪声点                     |
| 温度补偿         | 长时间测量是否漂移                     |

## 7. 如何验证 ToF / iToF 是否正确

### 7.1 平面距离测试

用白纸板或墙面放在固定距离。

| 操作               | 正确表现                               |
|--------------------|----------------------------------------|
| 纸板放 40cm        | 深度均值接近 400mm                     |
| 纸板放 80cm        | 深度均值接近 800mm                     |
| 纸板放 120cm       | 深度均值接近 1200mm                    |
| 纸板固定不动       | 深度均值和点云基本稳定                 |

### 7.2 左右方向测试

| 操作               | 正确表现                               |
|--------------------|----------------------------------------|
| 目标在左侧         | 点云整体偏左                           |
| 目标在中央         | 点云靠近中心                           |
| 目标在右侧         | 点云整体偏右                           |

### 7.3 前后层次测试

让一个人站在远处，把手伸到近处。

| 目标               | 正确表现                               |
|--------------------|----------------------------------------|
| 手                 | 深度更近                               |
| 身体               | 深度更远                               |
| 背景               | 更远或无效                             |

### 7.4 材质测试

| 材质               | 典型表现                               |
|--------------------|----------------------------------------|
| 白纸               | 回波强，适合基准测试                   |
| 皮肤               | 通常可测                               |
| 黑布               | 回波弱，有效点少                       |
| 玻璃               | 可能透明或产生假反射                   |
| 金属镜面           | 容易过曝或多路径                       |

## 8. ToF 与其他 3D 技术对比

| 技术       | 原理                         | 优点                       | 缺点                         |
|------------|------------------------------|----------------------------|------------------------------|
| ToF / iToF | 主动光飞行时间或相位差       | 实时、直接输出深度         | 受环境光、温度、反射率影响   |
| 双目       | 两个相机做视差匹配           | 不一定需要主动光           | 依赖纹理，弱纹理难匹配       |
| 结构光     | 投射图案，分析图案变形       | 近距离精度高               | 室外强光较难                 |
| LiDAR      | 激光扫描或阵列测距           | 远距离、精度高             | 成本较高                     |
| 单目 AI    | 神经网络估计深度             | 硬件简单                   | 绝对距离可靠性较低           |

## 11. 工程实现建议

ToF 工程实现可以按以下路径推进：

```text
硬件供电/光路确认
        ↓
I2C / SPI / USB / MIPI 通信确认
        ↓
初始化寄存器和调制参数
        ↓
采集 raw phase 或 depth frame
        ↓
解算 depth / amplitude / confidence
        ↓
过滤无效点和低置信点
        ↓
生成 point cloud
        ↓
做距离误差、稳定性、温度漂移验收
```

调试时建议按以下顺序观察：

```text
Amplitude 是否有主动回波
Distance 是否有有效距离
ROI valid 是否足够
距离是否随前后移动单调变化
点云是否随左右/前后移动同步变化
温度是否可控
```

不要只看一项参数。ToF 的判断必须把深度、幅度、有效点、曝光、温度和点云一起看。
