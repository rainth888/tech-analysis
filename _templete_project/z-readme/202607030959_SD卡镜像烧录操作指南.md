# SD卡镜像烧录操作指南 (2026-07-03)

本文档记录了在 Windows 系统下直接对 SD 卡进行扇区级原始镜像烧录的步骤及使用的脚本工具。

## 硬件配置
- **目标设备**：Generic Mass Storage (SD卡)
- **物理盘符/序号**：`PhysicalDrive2` (磁盘序号：2)
- **磁盘容量**：~59.48 GB (64GB 规格)
- **读卡器连接方式**：笔记本 Type-C 端口

## 软件配置
- **镜像源文件**：`E:\BaiduNetdiskDownload\rk3576-sd-buildroot-6.1-arm64-20260413.img`
- **镜像容量**：~3.7 GB (3,975,905,280 字节)
- **烧录脚本**：`z-scripts/flash_sd.ps1` (利用 PowerShell .NET API 进行扇区级直接数据读写，无需依赖第三方工具如 Rufus/Etcher)

## 操作步骤

### 1. 验证目标磁盘序号
在管理员模式的 PowerShell 下执行以下命令，确认 SD 读卡器属于哪个磁盘号（本操作确认为磁盘 2）：
```powershell
Get-Disk
```

### 2. 执行烧录脚本
在管理员模式的 PowerShell 中运行 `flash_sd.ps1`。该脚本会自动将磁盘脱机以避免 Windows 分区锁占用，读取镜像文件并以 1MB 的块大小进行流式写入，完成后重新使磁盘在线。
```powershell
powershell -ExecutionPolicy Bypass -File "z-scripts/flash_sd.ps1" -ImagePath "E:\BaiduNetdiskDownload\rk3576-sd-buildroot-6.1-arm64-20260413.img" -DiskNumber 2
```

> ⚠️ **警告**
> 镜像烧录会破坏目标磁盘（磁盘 2）上的所有数据与原有分区结构，烧录前请务必确认磁盘序号 2 对应的是正确的 SD 卡，避免误擦除系统盘或备份盘。
